# 3년 성과 흐름 — 검증에서 출발해 제품을 직접 고치고 재는 사람으로

> 2023.11 ~ 2026.11 · 온라인 교육 플랫폼(강의 판매·수강·결제·커뮤니티) + 부동산 중개 서비스
> QA 엔지니어로 입사 → 릴리스·일정 관리 → QA 리드 → 기획 → 백오피스 KR 오너 + 직접 개발 + AI 업무 환경 운영 (공식 직무는 QA)

표기: **[실측]** 원자료·측정 기록이 있는 값 · **[동료 측정]** 내가 관리했지만 측정은 동료가 한 값 · **[검증 중]** 기준을 못 넘어 인용을 보류한 값

## 1. QA 검수 — "검증했다"를 숫자로 말할 수 있게

## 2. FE 개발 — 원인을 찾은 사람이 직접 고친다

**사용자 웹 (Next.js / React, 커밋 110건)**
- 페이지 이동 직전 분석 이벤트 유실: 1차 수정 후 재발을 잡고 SDK 직렬 전송 구조까지 내려가 재현, 2차 수정 기준 제시(반영 대기) → [사례 03](cases/03-event-loss-before-navigation.md)
- 예외 없이 null을 돌려주는 코드가 폴백 체인을 끊어 안내 팝업이 안 뜨던 문제 수정
- 백엔드가 내려주는 "공개 예약" 필드를 프론트가 소비하지 않아 예약 교재가 노출되고 400이 나던 문제 수정
- 대기 신청 상태의 공유 버튼 누락, 상담 입구 A/B 노출, 광고 플랫폼 전용 구매 이벤트, iOS 다운로드 파일명 핫픽스

**운영 백오피스 (Vue 3 / Nuxt 3, 커밋 161건)**
- 만족도 조사 의견을 코드에서 원인 확인 → 범위 A(프론트 단독)는 직접 구현 → [사례 01](cases/01-backoffice-as-product.md)
- 세션 갱신 대기열이 폐기되며 요청이 증발하던 "무반응" 결함, 모달 드롭다운이 마스크 뒤에 깔리던 z-index 결함
- 할인율 입력 칸이 판매가를 변조하던 결함, 수강기간 일괄 변경의 2,000건 잘림 진단 → [사례 05](cases/05-silent-2000-cap.md)
- 팝업 복제(오랫동안 빈 함수), 날짜 포맷 분·월 뒤바뀜, 조 편성 엑셀에 조장 선발용 이력 열 추가

## 3. BE 개발 — 목록·건수·엑셀이 같은 조건을 보게

**Java / Kotlin Spring Boot (커밋 55건)**
- 고객 검색 결함: LIKE 이스케이프 누락 + 건수 쿼리만 옛 검색 타입 → 조건 조각 통합 → [사례 04](cases/04-search-zero-results.md)
- 상품별 통계 개선(강의 단위 보기, 알림 후 결제 인원·전환율, 알림 명단 엑셀에 결제 열) — 백엔드·프론트 함께, 운영 수치를 원천 DB와 대조해 통과
- 환불 관리 상품번호 검색(건수 쿼리 컬럼 누락이 핵심 함정)
- 선착순 마감 해제 기능, 대기 취소 알림의 선택 발송, 수강 현황 다중 상태 필터, 학습 등급 집계 제외 규칙
- 버그 수정도 CI 브랜치 규칙에 맞춰 올리고, 그 규칙을 내 작업 규칙서에 남김

## 5. 데이터 분석·성과 측정 — 감으로 내려지던 결정을 숫자로

| 질문 | 분석 | 바뀐 결정 |
|---|---|---|
| 시즌 프로모션의 결제를 누가 이끌었나 | 결제 기여: 홈 배너가 실시간 방송 플로팅 창의 **약 7배** | 다음 시즌 배치 우선순위 변경 (가설 반증) |
| 오픈 알림 신청자가 왜 결제까지 안 오나 | 퍼널 이탈의 병목은 발송 부족이 아니라 **알림 클릭률** | 발송 증량안이 효과 없음을 입증 |
| QA 지원 요청이 왜 밀리나 | 4주 인입 분류: 요청이 특정 인원에 집중, **즉시 대응이 필요한 건은 약 3분의 1** | 나머지는 배치 처리로 전환 가능하다는 결론 |
| 검색 유입이 왜 크게 줄었나 | 유입 경로별 분해(유료는 오히려 증가, 검색만 급감) → 검색 콘솔의 색인·노출·크롤 지표 → 봇 UA 크롤 표본 30건 → 검색엔진 공식 업데이트 일정 대조 | 색인은 정상인데 노출만 사라졌고, 절벽 날짜가 코어 업데이트 시작일과 일치 → **기술 원인을 닫고** 콘텐츠 품질 대응으로 범위 한정 |
| 운영 실수는 줄고 있나 | 지원 요청을 4개 유형으로 태깅, 휴먼에러 비율을 같은 정의로 매주 자동 집계 | 구성원 목표 두 개가 같은 원천 데이터를 쓰게 함 |
| 백오피스 개선이 체감되나 | 분기 고정 문항 만족도 | 7.29 → **8.82**, 개선 PR +96% |
