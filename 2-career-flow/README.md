# 2. 경력과 사례 — 사례 13건

> 경력 전체와 숫자의 정본은 [경력기술서](경력기술서.md)다. 이 페이지는 판단 과정을 보여 주는 사례 13건의 목록이다.
> 사례는 모두 **문제 → 진단 → 조치 → 결과 → 재사용할 원칙** 순서로 썼다. 진단과 반영은 다른 문제라, 결과까지 닫은 사례와 진단·결정 요청까지가 내 몫이었던 사례를 나눴다.
