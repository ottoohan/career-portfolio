# 10. 운영 공지 — 새 기능·정책 변경 안내

> 배포는 운영자가 쓰기 시작해야 끝난다. 공지는 **배경 → 바뀐 점 → 사용 방법 → 유의사항** 순서로 고정해서, 읽는 사람이 "왜 바뀌었고, 나는 무엇을 하면 되나"를 한 번에 알게 한다.

## 템플릿

```markdown
[새 기능 / 정책 변경] <기능 이름> — <언제부터>

■ 배경
<어떤 불편·문의 때문에 바꿨나. 1~2줄. 의견을 준 사람이 있으면 "○○ 의견 반영">

■ 바뀐 점
- 전: <지금까지는 어떻게 했나>
- 후: <이제는 어떻게 되나>
- 바뀌지 않는 것: <헷갈리기 쉬운 기존 동작>

■ 사용 방법
1. <메뉴 > 화면 > 버튼>
2. <입력값·선택값>
3. <결과 확인하는 곳>
(화면 캡처 1~2장)

■ 유의사항
- <되돌릴 수 없는 동작, 한도, 권한>
- <문제가 생기면: 문의 채널 · 담당자>

대상: <부서·역할> · 설명 세션: <일시, 필요할 때만>
```

## 채운 예시

```markdown
[새 기능] 강의 동영상 일괄 등록 — 오늘 배포

■ 배경
옵션이 여러 개인 강의는 강의실마다 영상을 하나씩 올리고 연결해야 해서,
매주 같은 작업을 옵션 수만큼 반복한다는 의견이 많았습니다.

■ 바뀐 점
- 전: 영상 1개씩 등록 → 챕터로 끌어다 놓기
- 후: 최대 20개를 한 번에 올리고, 챕터를 골라 한 번에 연결
- 바뀌지 않는 것: 이미 연결된 영상의 순서와 공개 예약은 그대로입니다

■ 사용 방법
1. 전시상품관리 > 해당 상품 > 커리큘럼 > [동영상 일괄 등록]
2. 파일 선택(최대 20개) → 연결할 챕터 선택
3. 저장 후 수강생 화면 미리보기에서 순서 확인

■ 유의사항
- 20개를 넘기면 나눠서 올려 주세요
- 연결을 잘못했으면 해당 영상만 연결 해제하면 됩니다(삭제되지 않음)

대상: 강의 운영 담당자 · 설명 세션: 원하는 팀은 대면으로 진행
```

## 쓰지 않을 때

- 운영자 화면이 바뀌지 않는 버그 수정은 공지하지 않는다. 공지가 많으면 중요한 공지가 묻힌다.
- 장애 안내는 이 양식이 아니라 장애 공지(현상·영향·임시 대응·복구 예정)로 낸다.
- 정책을 아직 정하지 못했으면 공지보다 결정 요청이 먼저다.

## 체크리스트

- [ ] 첫 줄에 기능 이름과 시작 시점이 있다
- [ ] "바뀌지 않는 것"을 적었다(같은 질문이 줄어든다)
- [ ] 사용 방법이 화면 경로로 적혀 있고, 캡처가 있다
- [ ] 되돌릴 수 없는 동작은 유의사항 맨 위에 있다
- [ ] 문의 채널을 적었다
- [ ] 배포 후 한두 주 동안 같은 기능 문의가 오는지 본다 → 오면 공지를 고친다

## 이 양식이 생긴 이유

배포 공지가 사람마다 형식이 달라, 같은 기능을 두고 "어디서 하나요"가 반복됐다. 순서를 고정한 뒤 공지를 운영 부서 채널에 직접 올렸다(새 기능 배포 안내·시연 95건, 2025.01~2026.11). → [경력기술서 운영지원 절](../2-career-flow/경력기술서.md#0-운영지원--운영-문의를-판정하고-닫기)
