# 한지만 — QA + 운영지원(Product Operations)

> **제품 품질 검증과 운영지원을 한 자리에서 맡습니다.** QA 5년(최근 3년 온라인 교육 플랫폼) — 결함을 막는 QA에, 운영자가 쓰는 도구를 개선하고 운영 문의의 원인을 판정해 닫는 운영지원을 더했습니다.
