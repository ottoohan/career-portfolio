의견마다 코드에서 원인을 먼저 확인

3

범위로 나눠 처리: 프론트 단독은 직접 구현, 서버 변경은 개발자와, 스키마 변경은 백엔드에 요청

9월 회차부터 모든 응답에 처리 현황을 회신. 9월 8점 이하였던 응답자 중 10월에도 답한 4명 가운데 2명이 점수를 올림

출처: 사내 월간 어드민 만족도 조사 원본(4·6~10월). 만족도는 자가 응답이라 보조 지표 — 결과 지표는 의견 처리 결과(9월 20건 중 12건 완료). 개선 PR 25 → 49건은 팀 작업량이라 보조

운영자들이 쓰는 백오피스는 요청이 오면 그때그때 고치는 도구였고, 무엇이 나아졌는지 아무도 몰랐습니다. 매달 같은 문항으로 조사하고, 의견마다 코드에서 원인을 확인해 누가 고칠 수 있는지로 범위를 나눴습니다. 그래프를 보시면 6월과 9월에 한 번씩 내려갔는데, 이것도 그대로 보여드립니다. 9월부터는 응답 하나하나에 처리 현황을 코멘트로 회신했고, 10월에 9.33으로 가장 높았습니다. 응답자는 회차마다 12명에서 26명, 고유 인원 31명입니다.
